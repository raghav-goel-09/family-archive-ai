# Family Archive AI

An AI-powered project designed to organize, process, and retrieve family archive data using AI and data processing techniques.

## Features
- Database-based data retrieval
- Data processing and organization
- Generative AI integration
- API-based access

## Tech Stack
- Python
- Generative AI
- SQL
- API

## Project Structure
- `1_database_retrieval.py` – Database retrieval
- `2_process_data.py` – Data processing
- `3_genai.py` – Generative AI functionality
- `4_main.py` – Main application workflow
- `api.py` – API implementation
- `schema.sql` – Database schema

## Setup
Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project using:

```bash
python 4_main.py
```
